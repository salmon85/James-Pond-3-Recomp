James Pond 3: Operation Starfish - static recompilation

This package does not contain the game ROM.

Put your No-Intro dump "James Pond 3 (USA, Europe).md" next to this file as
"jp3.md":

  Windows: next to JamesPond3Recomp.exe
  Linux:   next to the .AppImage

Then run the game. If the ROM is missing, the runner asks you to select it.

ROM identity: 2,097,152 bytes, CRC32 0x26F64B2A,
SHA-256 8f52e27945b96d6c37fda28c44d39d65d805cc0b58332f9b4a2eb26dff540d29.
